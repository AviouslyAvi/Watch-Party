Install userscript

Extension steps (skip if you used the userscript):

  1. Unzip the downloaded file. Remember where you put the unzipped folder.
  2. Open chrome://extensions in Chrome. (Copy-paste it — Chrome won't let links open this page.)
  3. Flip on Developer mode — the toggle is in the top-right corner of the page.
  4. Click Load unpacked (top-left, appears after Developer mode is on) and pick the unzipped folder.
  5. Click the puzzle-piece 🧩 in your Chrome toolbar and pin Watch-Party so the icon is always visible.
Trouble installing?
  • "Manifest file is missing or unreadable": you picked the zip or its parent folder. Pick the unzipped folder that directly contains manifest.json.
  • No "Load unpacked" button: Developer mode isn't on yet. Toggle is upper-right of the extensions page.
  • Chrome reopens and the extension is gone: Chrome occasionally disables unpacked extensions after a restart — re-enable it from chrome://extensions.
  • Edge / Brave / Arc: same steps, same page (edge://extensions, brave://extensions, etc.). Firefox is not yet supported.

2 Start a watch party

3 Joining someone else's party?

  1. Install the extension (step 1) if you haven't already.
  2. Open the link the host sent you.
  3. Click the Watch-Party icon in your toolbar to activate it on that tab. You'll see the chat panel slide in.

The extension stays dormant until you click the icon — that way it never touches sites you're not actively watching on.

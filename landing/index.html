Extension steps — for the zip download
  1. Unzip the downloaded file. Remember where you put the unzipped folder.
  2. Open chrome://extensions in Chrome. (Copy-paste it — Chrome won't let links open this page.)
  3. Flip on Developer mode — the toggle is in the top-right corner of the page.
  4. Click Load unpacked (top-left, appears after Developer mode is on) and pick the unzipped folder.
  5. Click the puzzle-piece 🧩 in your Chrome toolbar and pin Watch-Party so the icon is always visible.
Userscript steps — for the one-click install
  1. Install a userscript manager once. Recommended: Tampermonkey for Chrome (or Firefox). Alternatives: Violentmonkey, Greasemonkey.
  2. Click Install userscript above. Your userscript manager will pop up showing the script's metadata.
  3. Click Install inside that dialog. Reload any tab where you want to use Watch-Party.

Auto-updates on every release — no re-install on new versions.

Trouble installing?
  • Extension — "Manifest file is missing or unreadable": you picked the zip or its parent folder. Pick the unzipped folder that directly contains manifest.json.
  • Extension — no "Load unpacked" button: Developer mode isn't on yet. Toggle is upper-right of the extensions page.
  • Extension — Chrome reopens and it's gone: Chrome occasionally disables unpacked extensions after a restart — re-enable it from chrome://extensions.
  • Userscript — clicking the button shows raw code: Tampermonkey/Violentmonkey isn't installed yet, or isn't enabled. Install one of them first, then re-click.
  • Userscript — install dialog doesn't appear: some browsers block userscript URLs until you open the extensions page once. Open Tampermonkey's dashboard, then re-click Install userscript.
  • Edge / Brave / Arc: same steps, same page (edge://extensions, brave://extensions, etc.). Firefox is supported via the userscript path only — the extension is Chrome/Chromium-only for now.
